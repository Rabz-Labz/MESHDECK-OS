# Using MESHDECK

## First start

The first time MESHDECK starts it walks you through setup: set the clock (UK time; GMT or BST is
worked out for you) and choose whether to protect the deck with a PIN. Every step can be skipped
and changed later: the clock in SETTINGS, the PIN in SECURITY.

## The home screen

Eleven tiles, each opened by tapping it or pressing its key:

| Key | Tile | Key | Tile |
|---|---|---|---|
| 1 | MESSAGES | 6 | TERMINAL |
| 2 | MAP | 7 | SETTINGS |
| 3 | LIBRARY | 8 | DIAGNOSTICS |
| 4 | LOGBOOK | 9 | SECURITY |
| 5 | FILES | 0 | GAMES |
| A | TOOLS (timer, stopwatch, calculator) | | |

The last space shows the time, the date and the estimated battery time left. The status bar at
the top shows the battery and time left, the clock, and warnings such as LOCKED or NO KEYBOARD.

## Maps

MAP needs map packs and a place list on the SD card, in `MESHDECK/maps/`. None are supplied: you
make them on a PC from free Ordnance Survey data. [maps.md](maps.md) walks you through it for
your own area, from downloading the data to checking the map on the Tab5.

## Keys

Everything can be done by touch alone or by keyboard alone.

| Key | Does |
|---|---|
| 1-9, 0, A | open a home tile, from anywhere |
| Arrows | move between buttons |
| Enter | press the highlighted button |
| Esc | back one step |
| + / - | zoom, page or brightness, in apps that use them |
| Ctrl+P | save a screenshot to Files/Screenshots |
| Ctrl+N | change the colour theme (green, amber, red) |
| Ctrl+L | lock now (needs a PIN) |

The line at the bottom of the screen always says which keys do what on the current screen.

## Locking

With a PIN set, the deck locks when it starts, after a few minutes with no key or touch (choose
OFF, 2, 5 or 15 minutes in SECURITY), and on Ctrl+L. Type the PIN on the keyboard or the on-screen
pad. After 3 wrong tries you have to wait before trying again; see [security.md](security.md).

## Screenshots

Ctrl+P (or TAKE SCREENSHOT in SETTINGS) saves the whole screen as a PNG named by date and time,
e.g. `MESHDECK/Files/Screenshots/2026-11-01_1430.png`. They appear at the top of FILES.
